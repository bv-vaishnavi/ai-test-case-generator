# Client

React + TypeScript + Vite + Tailwind CSS frontend for MELO.

See the [root README](../README.md) for setup, architecture, screenshots scope, environment variables, and the end-to-end flow.

- `npm run dev`: local development server.
- `npm run build`: TypeScript and optimized production build.
- `npm run lint`: ESLint checks.
- `npm test`: Playwright desktop/mobile flow checks using deterministic API fixtures.
